# Master AI-Powered DevOps with CityOps

Learn AI-powered software delivery against **CityOps**, a production-grade civic reporting platform. Choose one platform and follow its modules in sequence. The tracks are intentionally independent: no lesson requires switching between GitHub and Azure DevOps.

## Choose Your Track

- **[GitHub](./content/github/README.md)** — 39 hands-on lessons and one curriculum preview covering GitHub Copilot, code quality, security, enterprise administration, and agentic delivery.
- **[Azure DevOps](./content/ado/README.md)** — Six-module curriculum outline covering Boards, Repos, Pipelines, Test Plans, Artifacts, Advanced Security, and AI-assisted operations.

## 15-Module Curriculum

### GitHub Track

1. **CityOps & GitHub Foundations** — Set up CityOps, understand its architecture, and establish a secure GitHub workflow.
2. **Enterprise Administration** — Govern identity, access, policies, Copilot, repositories, auditing, licensing, and adoption.
3. **Security** — Review and remediate application, dependency, code, and secret risks with appropriate governance.
4. **Code Quality** — Generate meaningful automated tests and evaluate engineering-quality evidence.
5. **AI-Assisted Development with GitHub Copilot** — Explore, plan, edit, and implement real CityOps changes in VS Code.
6. **Extend and Govern GitHub Copilot** — Use instructions, prompts, skills, custom agents, and MCP safely.
7. **GitHub Copilot CLI** — Bring governed Copilot workflows, MCP tools, and agent skills into the terminal.
8. **Spec-Driven Development** — Turn requirements into approved specifications and traceable implementations.
9. **Agentic Delivery & Operations on GitHub** — Use coding agents and governed automation to deliver and operate CityOps.

### Azure DevOps Track

1. **CityOps & Azure DevOps Foundations** — Set up an Azure DevOps project and map CityOps delivery into a governed team workflow.
2. **Plan and Collaborate with Boards & Repos** — Manage work, branches, policies, pull requests, and traceability.
3. **Build and Deploy with Azure Pipelines** — Create YAML CI/CD, environments, approvals, templates, and reusable delivery stages.
4. **Quality and Packages with Test Plans & Artifacts** — Connect manual and automated testing, publish evidence, and manage packages.
5. **Secure and Govern Azure DevOps** — Apply Advanced Security, permissions, service connections, secrets, and policy controls.
6. **AI-Powered Delivery & Azure Operations** — Use GitHub Copilot with Azure DevOps context and operate CityOps on Azure.

## Shared Project

Both tracks use the same CityOps repository and `main` branch. The platform is selected as a learning path—not as a branch or a second copy of the application.

CityOps includes multi-tenant isolation, role-based access control, PostgreSQL/PostGIS, Prisma, Auth.js, Azure OpenAI validation, and Azure infrastructure. These real constraints make every exercise representative of production delivery.
