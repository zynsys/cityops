# Getting Started: Secure & Govern Azure DevOps

> [!NOTE]
> This is a curriculum preview. The complete hands-on lessons for this Azure DevOps module are still being authored.

## Module Outcome

Protect CityOps delivery with least privilege, governed credentials, actionable scanning, and auditable approvals.

## Planned Lessons

1. Review organization, project, repository, pipeline, and environment permissions.
2. Apply least privilege to users, groups, agents, and service identities.
3. Protect secrets with Azure Key Vault and governed service connections.
4. Configure dependency, code, and secret scanning with GitHub Advanced Security for Azure DevOps.
5. Triage findings and add proportionate security gates.
6. Audit pipeline changes, approvals, retention, and production access.

## Hands-On Scenario

Harden a CityOps deployment path and remediate a realistic finding without bypassing the team’s delivery controls.
