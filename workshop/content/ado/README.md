# Azure DevOps Track

Follow these six modules in sequence to master AI-powered DevOps with CityOps on Azure DevOps. This is the approved curriculum outline; hands-on lesson content will be added incrementally.

## 1. CityOps & Azure DevOps Foundations

- Create or select the Azure DevOps organization and project.
- Import or connect the CityOps repository without introducing a second curriculum branch.
- Configure teams, areas, iterations, permissions, and service identities.
- Run CityOps locally and understand its architecture, lifecycle, RBAC, and multi-tenancy constraints.
- Establish the delivery flow from work item to production evidence.

## 2. Plan and Collaborate with Boards & Repos

- Model epics, features, user stories, bugs, and tasks for CityOps.
- Use queries, backlogs, sprint boards, dashboards, and delivery plans.
- Adopt a `main`-based branch and pull-request workflow.
- Configure branch policies, required reviewers, CODEOWNERS-equivalent ownership, and build validation.
- Maintain traceability from requirement to commit, pull request, build, and deployment.

## 3. Build and Deploy with Azure Pipelines

- Build CityOps with multi-stage YAML pipelines.
- Validate formatting, linting, tests, Prisma generation, and the Next.js production build.
- Package and publish deployment artifacts or container images.
- Use templates, variable groups, environments, checks, and approvals.
- Deploy CityOps infrastructure and application components to Azure with promotion controls.

## 4. Quality and Packages with Test Plans & Artifacts

- Design test plans, suites, cases, configurations, and exploratory sessions.
- Connect manual tests to CityOps user stories and defects.
- Run unit, integration, Playwright, accessibility, and load tests in pipelines.
- Publish test results, coverage, screenshots, traces, and other diagnostic evidence.
- Version and consume internal packages through Azure Artifacts feeds.

## 5. Secure and Govern Azure DevOps

- Apply least-privilege organization, project, repository, pipeline, and environment permissions.
- Protect secrets with Azure Key Vault and governed service connections.
- Configure dependency, code, and secret scanning with GitHub Advanced Security for Azure DevOps.
- Triage findings and enforce security gates without weakening developer flow.
- Audit pipeline changes, approvals, retention, and production access.

## 6. AI-Powered Delivery & Azure Operations

- Use GitHub Copilot in VS Code while grounding work in Azure Boards and Azure Repos context.
- Connect approved MCP or API integrations to retrieve work items, pull requests, builds, and test evidence.
- Generate plans, YAML changes, tests, release notes, and incident hypotheses with human review.
- Deploy and observe CityOps using Azure Monitor and Application Insights.
- Close the loop from operational insight to an Azure Boards work item and governed delivery.

## Learning Outcome

By the end of the track, you can move a CityOps requirement from Azure Boards through secure Azure Repos collaboration, tested Azure Pipelines delivery, and evidence-driven Azure operations.
