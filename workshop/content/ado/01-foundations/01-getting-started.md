# Getting Started: CityOps & Azure DevOps Foundations

> [!NOTE]
> This is a curriculum preview. The complete hands-on lessons for this Azure DevOps module are still being authored.

## Module Outcome

Establish a governed Azure DevOps home for CityOps and understand the application constraints that every delivery workflow must protect.

## Planned Lessons

1. Create or select an Azure DevOps organization and project.
2. Configure teams, area paths, iterations, permissions, and service identities.
3. Connect CityOps to Azure Repos while retaining one canonical `main` branch.
4. Run CityOps locally and tour the citizen-to-council report lifecycle.
5. Map CityOps architecture, RBAC, multi-tenancy, and data ownership to delivery controls.
6. Trace the target lifecycle from work item through deployment evidence.

## Hands-On Scenario

Onboard the CityOps team into Azure DevOps and create a safe project baseline that later modules can build upon.
