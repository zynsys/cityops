# Getting Started: AI-Powered Delivery & Azure Operations

> [!NOTE]
> This is a curriculum preview. The complete hands-on lessons for this Azure DevOps module are still being authored.

## Module Outcome

Use reviewed AI assistance and Azure operational evidence to improve CityOps delivery without surrendering governance.

## Planned Lessons

1. Ground GitHub Copilot in Azure Boards and Azure Repos context.
2. Connect approved MCP or API tools for work items, pull requests, builds, and tests.
3. Generate reviewed plans, YAML changes, tests, and release notes.
4. Observe CityOps with Azure Monitor and Application Insights.
5. Investigate an operational signal and form an evidence-backed hypothesis.
6. Create and deliver a traced Azure Boards improvement from that insight.

## Hands-On Scenario

Move from a CityOps operational alert to a reviewed backlog item, validated code change, and governed deployment.

## Track Completion

You can now manage the complete CityOps delivery loop on Azure DevOps—from planning through secure deployment and operations.
