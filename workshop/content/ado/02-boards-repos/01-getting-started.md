# Getting Started: Plan & Collaborate with Boards and Repos

> [!NOTE]
> This is a curriculum preview. The complete hands-on lessons for this Azure DevOps module are still being authored.

## Module Outcome

Plan CityOps work, collaborate safely in Azure Repos, and preserve traceability from requirement to reviewed code.

## Planned Lessons

1. Model epics, features, user stories, bugs, and tasks for CityOps.
2. Organize backlogs, sprints, queries, dashboards, and delivery plans.
3. Adopt a `main`-based branch and pull-request workflow.
4. Configure branch policies, required reviewers, and build validation.
5. Link work items, commits, pull requests, builds, and deployments.
6. Review a tenant-sensitive CityOps change with explicit acceptance criteria.

## Hands-On Scenario

Plan and review a CityOps report-lifecycle enhancement while enforcing ownership, policy, and evidence at every handoff.
