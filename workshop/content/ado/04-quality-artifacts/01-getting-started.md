# Getting Started: Quality & Packages with Test Plans and Artifacts

> [!NOTE]
> This is a curriculum preview. The complete hands-on lessons for this Azure DevOps module are still being authored.

## Module Outcome

Connect manual quality practices, automated test evidence, and package management to CityOps requirements.

## Planned Lessons

1. Design test plans, suites, cases, configurations, and exploratory sessions.
2. Link tests and defects to CityOps user stories.
3. Run unit, integration, Playwright, accessibility, and load tests in pipelines.
4. Publish results, coverage, screenshots, traces, and diagnostics.
5. Create and govern an Azure Artifacts feed.
6. Version, publish, and consume a reusable internal package.

## Hands-On Scenario

Validate the citizen reporting journey with both manual and automated evidence, then publish a reusable CityOps package.
