# Getting Started: Build & Deploy with Azure Pipelines

> [!NOTE]
> This is a curriculum preview. The complete hands-on lessons for this Azure DevOps module are still being authored.

## Module Outcome

Build a reusable, governed YAML pipeline that validates, packages, and promotes CityOps through Azure environments.

## Planned Lessons

1. Create the first multi-stage Azure Pipelines YAML definition.
2. Run formatting, linting, tests, Prisma generation, and the Next.js production build.
3. Publish application artifacts or container images.
4. Extract reusable templates and govern variables.
5. Configure environments, approvals, checks, and deployment evidence.
6. Deploy CityOps infrastructure and application components to Azure.

## Hands-On Scenario

Take a reviewed CityOps change from `main` to a controlled Azure environment with reproducible build and deployment evidence.
