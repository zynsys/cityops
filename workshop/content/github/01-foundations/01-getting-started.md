# Getting Started

> **Module**: Project Overview | **Time**: 5 min

Welcome to the CityOps workshop. This module gives you the context and local environment you need before using GitHub Copilot against the codebase.

## What You'll Learn

By the end of this module, you'll be able to:

- Explain the CityOps product and its citizen-to-council workflow
- Prepare the required accounts, tools, and local services
- Run the application and explore its primary user journeys
- Identify the architecture, data model, RBAC, and multi-tenant boundaries

## Before You Begin

- Have a GitHub account with access to GitHub Copilot
- Open the CityOps repository in Visual Studio Code
- Keep the integrated terminal available for setup and validation

> [!TIP]
> Complete this module first if CityOps is new to you. The remaining modules assume you recognise its core folders and security boundaries.

## Learning Path

1. Review the workshop goals and CityOps domain
2. Prepare your development environment
3. Follow a report through the application
4. Explore the codebase architecture and security model

You're ready to begin. Select **Next** to open **Workshop Overview**.
