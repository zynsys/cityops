# Getting Started

> **Module**: Agentic Development | **Time**: 5 min

This advanced module explores how to delegate, review, and coordinate increasingly autonomous development work while keeping humans accountable for the result.

## What You'll Learn

By the end of this module, you'll be able to:

- Delegate a well-scoped issue to Copilot Coding Agent
- Review and iterate on AI-generated pull requests
- Run work with background agents
- Design multi-step and multi-agent workflows
- Add lifecycle hooks that enforce project guardrails

## Before You Begin

- Complete the Developer Productivity module or have equivalent Agent Mode experience
- Push your CityOps fork to GitHub
- Confirm the required coding-agent and agentic features are enabled for your account

> [!IMPORTANT]
> Greater autonomy requires stronger boundaries. Keep tasks scoped, provide explicit acceptance criteria, and require build, test, security, and tenant-isolation evidence.

## Learning Path

Begin with one delegated issue, learn to review the result, then progress to background, orchestrated, and multi-agent work before adding automated hooks.

You're ready to begin. Select **Next** to open **Copilot Coding Agent**.
