# Getting Started

> **Module**: GitHub Copilot CLI | **Time**: 5 min

This module brings GitHub Copilot into your terminal so you can explore, explain, and modify CityOps without leaving your command-line workflow.

## What You'll Learn

By the end of this module, you'll be able to:

- Install and authenticate GitHub Copilot CLI
- Use common commands against a real repository
- Connect MCP servers for richer tool access
- Reuse Agent Skills in terminal-first workflows

## Before You Begin

- Open a terminal in the CityOps repository root
- Confirm Git and Node.js are installed
- Have a GitHub account with GitHub Copilot access

> [!CAUTION]
> Read every generated command before approving it, especially commands that install software, modify files, or access remote services.

## Learning Path

You will set up the CLI first, practise its core workflow, and then extend it with MCP servers and Agent Skills.

You're ready to begin. Select **Next** to open **CLI Installation**.
