# Getting Started

> **Module**: Spec-Driven Development | **Time**: 5 min

This module turns an idea into traceable requirements, an implementation plan, working code, and validation evidence using Spec Kit and GitHub Copilot.

## What You'll Learn

By the end of this module, you'll be able to:

- Install and initialise Spec Kit
- Convert a feature request into testable requirements
- Clarify ambiguity before implementation begins
- Implement and validate a feature from an approved specification

## Before You Begin

- Open the CityOps repository in Visual Studio Code
- Confirm GitHub Copilot Chat and Agent Mode are available
- Choose a small CityOps feature that can be validated locally

> [!TIP]
> A specification is a shared decision record, not a longer prompt. Resolve unclear behaviour and security constraints before asking an agent to implement it.

## Learning Path

You will set up the workflow, author a specification, and then use that specification as the contract for implementation and validation.

You're ready to begin. Select **Next** to open **Spec Kit Installation**.
