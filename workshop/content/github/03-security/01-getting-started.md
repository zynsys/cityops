# Getting Started

> **Module**: Security | **Time**: 5 min

This module uses GitHub Copilot and GitHub security capabilities to identify, prioritize, and remediate security risks in CityOps without replacing expert review.

## What You'll Learn

By the end of this module, you'll be able to:

- Review authentication, authorization, RBAC, and tenant-isolation controls
- Identify secrets, sensitive logging, and common application security weaknesses
- Distinguish genuine findings from false positives
- Turn validated findings into actionable, responsibly disclosed remediation work

## Before You Begin

- Complete **CityOps & GitHub Foundations** and understand the application architecture
- Review the four CityOps roles and multi-tenant data rules
- Confirm you understand your organization's process for handling security findings

> [!IMPORTANT]
> Do not place exploit details, credentials, personal data, or unpatched high-severity findings in public prompts or issues. Follow your organization's disclosure and incident-response process.

## Learning Path

Begin with a threat-aware review of CityOps API, middleware, authentication, and secret-handling paths. Validate every AI-generated finding before prioritizing or remediating it.

You're ready to begin. Select **Next** to open **Security Review with Copilot**. After this module, continue to **Code Quality** to turn security expectations into repeatable engineering feedback.
