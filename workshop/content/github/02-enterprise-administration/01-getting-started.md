# Getting Started: Enterprise Administration

> [!NOTE]
> This is a curriculum preview. The complete hands-on lessons for this GitHub Enterprise Administration module are still being authored.

## Module Outcome

Administer GitHub Enterprise and GitHub Copilot with identity, policy, access, governance, and adoption controls appropriate for an organization delivering CityOps.

## Planned Lessons

1. Understand enterprise, organization, repository, and team administration boundaries.
2. Configure enterprise identity with SAML single sign-on, SCIM provisioning, and approved authentication policies.
3. Design least-privilege roles, teams, repository access, and outside-collaborator governance.
4. Configure GitHub Copilot policies, feature availability, content exclusions, and responsible-use guardrails.
5. Apply organization rulesets, branch protections, repository policies, and audit controls.
6. Review licensing, usage, adoption, audit-log evidence, and operational administration workflows.

## Hands-On Scenario

Create an enterprise governance baseline for teams building CityOps, balancing developer productivity with identity, security, compliance, and audit requirements.
