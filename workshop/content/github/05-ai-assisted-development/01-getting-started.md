# Getting Started

> **Module**: Developer Productivity | **Time**: 5 min

This module introduces the core GitHub Copilot interaction modes in Visual Studio Code and helps you choose the right level of assistance for each development task.

## What You'll Learn

By the end of this module, you'll be able to:

- Explore unfamiliar code safely with Ask Mode
- Make focused edits with Inline Chat and Edit Mode
- Design an implementation before coding with Plan Mode
- Delegate multi-file work with Agent Mode
- Match approval controls to the risk of a task

## Before You Begin

- Complete the Project Overview module or be familiar with CityOps
- Open the CityOps repository in Visual Studio Code
- Confirm the GitHub Copilot extension is installed and signed in

> [!IMPORTANT]
> CityOps is multi-tenant. Review every generated database query for a tenant boundary before accepting a change.

## Learning Path

You will progress from read-only exploration to increasingly autonomous changes: **Ask → Inline/Edit → Plan → Agent → Approvals**.

You're ready to begin. Select **Next** to open **Ask Mode**.
