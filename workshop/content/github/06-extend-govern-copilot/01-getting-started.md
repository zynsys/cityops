# Getting Started

> **Module**: Extending Copilot | **Time**: 5 min

This module shows how to make GitHub Copilot more effective by giving it reusable project context, specialised instructions, and external tools.

## What You'll Learn

By the end of this module, you'll be able to:

- Guide generated code with repository and path-specific instructions
- Create reusable prompt files for recurring tasks
- Define focused custom agents and Agent Skills
- Connect external tools through Model Context Protocol (MCP)
- Evaluate community customisations before adopting them

## Before You Begin

- Open the CityOps repository in Visual Studio Code
- Confirm GitHub Copilot Chat is available
- Review `.github/copilot-instructions.md` to understand the current project guidance

> [!TIP]
> Treat every customisation as versioned project code: keep it focused, review it with your team, and test its effect on representative prompts.

## Learning Path

Start with passive context, progress to reusable workflows, and finish with tool-connected agents: **Instructions → Prompts → Agents → Skills → MCP → Community**.

You're ready to begin. Select **Next** to open **Custom Instructions**.
