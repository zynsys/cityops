# GitHub Track

Follow these nine modules in sequence to master AI-powered DevOps with CityOps on GitHub.

## 1. CityOps & GitHub Foundations

Set up CityOps, tour the citizen and staff workflows, understand the architecture, and establish a safe GitHub development baseline.

**Current learning material:** [`01-foundations/`](./01-foundations/)

## 2. Enterprise Administration

Govern identity, access, Copilot policy, repository rules, audit evidence, licensing, and adoption across GitHub Enterprise.

**Curriculum preview:** [`02-enterprise-administration/`](./02-enterprise-administration/)

## 3. Security

Review authentication, authorization, RBAC, tenant isolation, secrets, and sensitive logging. Validate Copilot findings before prioritizing and remediating risks.

**Current learning material:** [`03-security/`](./03-security/)

**Planned additions:** dependency protection, code scanning, secret protection, security campaigns, and governed remediation workflows.

## 4. Code Quality

Generate focused unit and integration tests, build Playwright coverage for CityOps user journeys, and evaluate generated assertions and regression evidence.

**Current learning material:** [`04-code-quality/`](./04-code-quality/)

## 5. AI-Assisted Development with GitHub Copilot

Use Ask, Inline Chat, Edit, Plan, and Agent experiences to understand and change production-grade CityOps code while preserving RBAC and tenant isolation.

**Current learning material:** [`05-ai-assisted-development/`](./05-ai-assisted-development/)

## 6. Extend and Govern GitHub Copilot

Create repository instructions, reusable prompts, custom agents, skills, and MCP integrations. Apply boundaries that make agent behavior predictable and reviewable.

**Current learning material:** [`06-extend-govern-copilot/`](./06-extend-govern-copilot/)

## 7. GitHub Copilot CLI

Install and authenticate GitHub Copilot CLI, use terminal-native AI assistance against CityOps, and combine command-line sessions with MCP servers and Agent Skills.

**Current learning material:** [`07-copilot-cli/`](./07-copilot-cli/)

## 8. Spec-Driven Development

Turn requirements into approved specifications, traceable plans, and validated implementations using Spec Kit and GitHub Copilot.

**Current learning material:** [`08-spec-driven-development/`](./08-spec-driven-development/)

## 9. Agentic Delivery & Operations on GitHub

Delegate bounded work to coding agents, review generated pull requests, coordinate background and multi-agent workflows, and add lifecycle hooks and operational feedback.

**Current learning material:** [`09-agentic-delivery-operations/`](./09-agentic-delivery-operations/)

## Learning Outcome

By the end of the track, you can move a CityOps requirement from idea to secure, tested, reviewed, and observable delivery using GitHub and GitHub Copilot.
