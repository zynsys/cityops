# Getting Started

> **Module**: Code Quality | **Time**: 5 min

This module uses GitHub Copilot to design meaningful automated tests and improve CityOps code quality without replacing engineering judgement.

## What You'll Learn

By the end of this module, you'll be able to:

- Generate focused unit and integration tests
- Build Playwright coverage for complete user journeys
- Evaluate generated tests for meaningful assertions and edge cases
- Use test evidence to identify maintainability and regression risks

## Before You Begin

- Ensure CityOps dependencies are installed
- Confirm the existing test suite can run in your environment
- Be familiar with the report lifecycle and the four CityOps roles

> [!IMPORTANT]
> A generated test is useful only when it can fail for the right reason. Review assertions, fixtures, tenant boundaries, and negative cases before keeping it.

## Learning Path

Move through the testing pyramid from focused code-level tests to complete browser journeys, applying the same critical thinking to every generated assertion and fixture.
