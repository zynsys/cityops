Learn GitHub Copilot with a Real-World App

Go beyond autocomplete. Master the full spectrum of GitHub Copilot — CLI, MCP Servers, Custom Agents, Agent Skills, Agentic Workflows, and Multi-Agent Development — using CityOps, a production-grade civic reporting platform.

🚀 Get Started ⭐ GitHub Repo

What You'll Learn

📝

Custom Instructions

Configure Copilot with project-specific context, coding standards, and prompt files tuned to the CityOps codebase.

💻

Copilot CLI

Use Copilot directly from the terminal to explore, explain, and modify a real Next.js + Prisma codebase.

🔌

MCP Servers

Connect GitHub and PostgreSQL MCP servers to drive database-aware, issue-linked code changes.
⚡

Agent Skills

Explore and create reusable SKILL.md definitions that give agents domain expertise in CityOps workflows.

🤖

Custom Agents

Build specialised agents like a RBAC reviewer or database migration assistant tailored to CityOps conventions.

🔄

Agentic Workflows

Chain complex multi-step tasks — migration, API route, UI component — in a single autonomous agent session.

👥

Multi-Agent Development

Orchestrate parallel agents working simultaneously on different layers of the stack, then coordinate the merge.

🔍

Code Review & Security

Use Copilot to review PRs, identify security gaps in auth middleware, and validate tenant isolation logic.

📋

Plan Mode

Draft structured architecture plans before writing code. Iterate with the Plan Agent until the design is right, then hand off to the implementation agent.

🌤️

Background Agents

Offload parallel tasks to background and cloud agents. Work on one thing while Copilot implements another, then review the result.

🪝

Agent Hooks

Enforce policies and automate workflows at agent lifecycle events — lint on file save, block destructive commands, inject context at session start.

🎚️

Approval Types

Control how much autonomy Agent Mode has — from step-by-step approval to fully autonomous Autopilot for well-scoped tasks.

Prerequisites

✓ GitHub account with Copilot subscription
✓ VS Code with GitHub Copilot extension
✓ Node.js 20+ installed
✓ Git installed and configured
✓ Docker Desktop — for PostgreSQL (with PostGIS) and Mailpit email testing
✓ Basic familiarity with TypeScript & SQL
✓ Azure account — free tier available at azure.microsoft.com/free
✓ Azure OpenAI service instance with a vision-capable model deployed (e.g. gpt-4o)
